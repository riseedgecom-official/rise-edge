# Rise Edge Academy – নতুন অ্যাপ (সেটআপ গাইড)

কোচিং সেন্টারের ছাত্র, শিক্ষক ও অ্যাডমিনের জন্য একটি অ্যাপ। ফোনে ইনস্টল করা যায় (PWA)। বাংলা ও ইংরেজি দুই ভাষাতেই চলে।
কোনো সার্ভার বা বিল্ড টুল লাগে না: ফাইলগুলো GitHub এ আপলোড করলেই চলে, ডাটাবেস Firebase (ফ্রি Spark প্ল্যান)।

> পুরনো অ্যাপের ডেটা এই নতুন ডাটাবেসে আসে না। নতুন করে ব্যাচ, শিক্ষক ও ছাত্র যোগ করতে হবে।

---

## সেটআপ (একবারই করতে হবে, ফোন থেকেই হবে)

### ধাপ ১ — GitHub এ নতুন রিপো বানান
1. github.com এ লগইন করে **New repository** চাপুন।
2. নাম দিন (যেমন `rise-edge`)। **Public** রাখুন (ফ্রি GitHub Pages এর জন্য Public লাগে)। **Create repository**।

### ধাপ ২ — ফাইল আপলোড
1. রিপোতে **Add file → Upload files** চাপুন।
2. এই ফোল্ডারের **সব ফাইল** বেছে নিন (ফোল্ডার নয়, ফাইলগুলো: `index.html`, `app.js`, `app.css`, `config.js`, `sw.js`, `manifest.webmanifest`, `logo.jpg`, চারটি `icon-*.png`, সব `lib-*.js`, সব `pages-*.js`, `data-syllabus.js`, `check.html`, `firestore.rules`, `README.md`)।
3. নিচে **Commit changes** চাপুন।

### ধাপ ৩ — Firebase প্রজেক্ট
1. console.firebase.google.com → **Create a project** (Google Analytics বন্ধ রাখুন)।
2. **Build → Authentication → Get started → Sign-in method → Email/Password** চালু করে Save।
3. **Build → Firestore Database → Create database** → লোকেশন **asia-south1 (Mumbai)** → **Production mode** → Create।
4. Firestore এর **Rules** ট্যাবে যান। যা লেখা আছে সব মুছে, রিপোর `firestore.rules` ফাইলের পুরো লেখা পেস্ট করুন → **Publish**।
5. **Project settings (⚙) → Your apps → Web (`</>`)** → অ্যাপের নাম দিয়ে Register। যে `firebaseConfig` দেখাবে, তার চারটি মান কপি করুন: `apiKey`, `authDomain`, `projectId`, `appId`।
6. GitHub এ রিপোর `config.js` খুলুন → ✏️ (Edit) → `PASTE_...` লেখাগুলোর জায়গায় ওই মান বসান (কোটেশন `" "` রেখে) → **Commit changes**।

> এই মানগুলো গোপন নয়। ডাটা সুরক্ষিত রাখে `firestore.rules`, তাই ধাপ ৩.৪ ভুলবেন না।

### ধাপ ৪ — GitHub Pages চালু
রিপোর **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**।
১–২ মিনিট পর ঠিকানা পাবেন: `https://আপনার-ইউজারনেম.github.io/রিপোর-নাম/`

### ধাপ ৫ — Firebase কে ওয়েবসাইট চেনানো
Firebase → **Authentication → Settings → Authorized domains → Add domain** → `আপনার-ইউজারনেম.github.io` (শুধু ডোমেইন, পুরো ঠিকানা নয়)।

### ধাপ ৬ — সেটআপ চেক
ব্রাউজারে `…github.io/রিপোর-নাম/check.html` খুলুন। সব লাইন সবুজ (✔) হলে ঠিক আছে। লাল (✘) থাকলে ওখানেই কী করতে হবে লেখা আছে।

### ধাপ ৭ — অ্যাডমিন বানান (প্রথমবার)
অ্যাপ খুলুন → সাইন-ইন পেজের নিচে **First-time setup (admin only)** → নাম, **আসল ইমেইল**, পাসওয়ার্ড দিন → **Create admin**।
(ইমেইল আসল দিন: পাসওয়ার্ড ভুলে গেলে ওই ইমেইলে রিসেট লিংক আসবে।) সেটআপ একবার হয়ে গেলে ওই বাটন আর দেখা যায় না, কেউ দ্বিতীয় অ্যাডমিন বানাতে পারে না।
এরপর Class 4–12 এর ব্যাচ নিজে থেকেই তৈরি হয়ে যায় (Class 9–12 এ Science / Commerce / Arts আলাদা)।

## লগইন কীভাবে কাজ করে
| কে | লগইন আইডি | উদাহরণ |
|---|---|---|
| ছাত্র | রোল নম্বর | `REAS-2026-001` |
| শিক্ষক / কো-অ্যাডমিন | রোল নম্বর | `REAT-2026-001` |
| অ্যাডমিন | ইমেইল বা নাম | |

* **অ্যাডমিন যোগ করলে** (Students / Teachers → Add): রোল ও একটি অস্থায়ী পাসওয়ার্ড দেখাবে (কপি, SMS, WhatsApp বা ইমেইলে পাঠানো যায়)। প্রথম লগইনেই নিজের পাসওয়ার্ড বেছে নিতে হয়।
* **নিজে রেজিস্ট্রেশন:** সাইন-ইন পেজে **New registration** → ছাত্র/শিক্ষক তথ্য ও নিজের পাসওয়ার্ড দেয় → লগইন আইডি পায়। **অ্যাডমিন বা কো-অ্যাডমিন অনুমোদন না দেওয়া পর্যন্ত** শুধু ড্যাশবোর্ড ও প্রোফাইল খোলা থাকে। অনুমোদন: **Registrations** পেজ। রেজিস্ট্রেশন বন্ধ/চালু করার সুইচও ওখানে।
* **পাসওয়ার্ড ভুলে গেলে:** সাইন-ইন পেজে **Forgot password?**
  * অ্যাডমিন (আসল ইমেইল): ইমেইলে রিসেট লিংক যায়।
  * ছাত্র/শিক্ষক: নাম ও ফোন দিয়ে অনুরোধ পাঠায়। অ্যাডমিন **Registrations** এ গিয়ে **New password** চাপলে নতুন অস্থায়ী পাসওয়ার্ড পায় এবং তাকে পাঠিয়ে দেয়।

### ডিজিটাল আইডি কার্ড
সাদা কার্ড, ওপরে গোল লোগো, নীল ফ্রেম ও সোনালি কোণ, বাঁ দিকে ছবি ও QR, ডান দিকে নাম / রোল / ক্লাস / ব্যাচ / অভিভাবকের নাম / অভিভাবকের ফোন। ছবি দেয় ছাত্র নিজে (Profile → Change photo)। প্রিন্ট বা PDF: কার্ড খুলে **Print / Save PDF**।

### ছাত্রের ফি দেওয়া
Fees → বাকি মাস চাপুন → **Cash** (অ্যাডমিন যাচাই করে অনুমোদন দেন) অথবা **Online** (ট্রানজেকশন আইডি ও স্ক্রিনশট) → **Send for approval**। অনুমোদনের পর রসিদ পাওয়া যায়।
ফি যেভাবে ঠিক হয় (ক্রম): ব্যক্তিগত ফি → ওই মাসে ব্যাচের প্রকাশিত ফি → ব্যাচের ফি → সাধারণ ফি (Fees → Add fee → Fee settings)।

### ফোন থেকে ফাইল পাঠানো (Android)
অ্যাপটি Chrome থেকে **Install app / Add to Home screen** করুন। তারপর Files, Drive বা WhatsApp এ কোনো PDF/ছবি চেপে **Share → Rise Edge** → Homework / Suggestion / Exam solution বেছে, এক বা একাধিক ব্যাচ বেছে **Send**। ফাইল সর্বোচ্চ ১২ MB। বড় ফাইলের জন্য Google Drive লিংক দেওয়া ভালো।

### অভিভাবককে ইমেইল (ঐচ্ছিক, ফ্রি)
SMS ও WhatsApp কোনো সেটআপ ছাড়াই চলে (আপনার ফোনের অ্যাপ খোলে)। ইমেইল চাইলে:
1. emailjs.com এ ফ্রি অ্যাকাউন্ট → **Email Services** এ আপনার ইমেইল যুক্ত করুন।
2. **Email Templates → Create** → To Email: `{{to_email}}`, Subject: `{{subject}}`, Content: `{{message}}` → Save।
3. অ্যাপে Settings → Email (EmailJS) এ **Public key**, **Service ID**, **Template ID** বসিয়ে Save → **Send test email**।

## ফ্রি প্ল্যানে সীমা (Firebase Spark)
* প্রতিদিন ৫০,০০০ ডেটা পড়া ও ২০,০০০ লেখা ফ্রি। অ্যাপ এমনভাবে বানানো যে একজন ছাত্রের একটা সেশনে প্রায় ২৫–৮০ পড়া লাগে; শত খানেক ছাত্রে কোনো সমস্যা নেই। কোটা শেষ হলে অ্যাপ জানায়; পরদিন আবার চলে।
* ফাইল Firestore এর ভেতরেই টুকরো করে রাখা হয় (Storage ফি-তে নেই)। মোট ১ GiB জায়গা ফ্রি; বড় ফাইল Drive লিংক দিয়ে দিন।
* ফ্রি প্ল্যানে **অটো ব্যাকআপ নেই**। গুরুত্বপূর্ণ জিনিস (রেজাল্ট শিট, রসিদ, রিপোর্ট) মাঝে মাঝে PDF করে রাখুন।
* অ্যাডমিন কোনো ছাত্র মুছলে তার প্রোফাইল ও ডেটা মুছে যায়, সে আর ঢুকতে পারে না। রোল নম্বর আবার ব্যবহার হয় না।

## সমস্যা হলে
| বার্তা | কী করবেন |
|---|---|

| This domain is not authorized | ধাপ ৫ |
| config.js has a wrong Firebase key | ধাপ ৩.৬: মানগুলো আবার কপি করুন |

| আপডেটের পর পুরনো চেহারা | অ্যাপ বন্ধ করে আবার খুলুন (নতুন ভার্সন নেটওয়ার্ক থেকে আসে) |

সব ঠিক আছে কিনা দেখতে যেকোনো সময় `check.html` খুলুন।

## ডেভেলপারদের জন্য (সংক্ষেপে)
* কোনো বিল্ড নেই: ES modules + Firebase JS SDK 10.12.2 (gstatic)। `lib-db.js` একমাত্র ফাইল যা Firebase ছোঁয়; বাকি সব `db.get/list/recent/set/upd/add/del/batch` ব্যবহার করে।
* `app.js` শেল ও রাউটার (`#/page`); `pages-*.js` প্রতিটি `page("name", render)` দিয়ে পেজ নিবন্ধন করে; লেখা `t("English text")` + `addBN({...})` (বাংলা অনুবাদ)।
* ভূমিকা: admin | co-admin (`teacher` + `ca:true`) | teacher (`bids`, `pub`) | student। `firestore.rules` তে প্রতিটি কালেকশনের অনুমতি ও কারণ লেখা আছে।
* মাসের সংখ্যা/র‍্যাঙ্ক প্রতিটি ব্যাচের জন্য একটাই ডকুমেন্টে (`bstat/{batchId}`), যা ছাত্ররা পড়ে। হাজিরা/নম্বর/হোমওয়ার্ক সেভের পর অ্যাপ এটি আবার হিসাব করে।
* নোটিশ ও লগের ডকুমেন্ট আইডি সময় অনুযায়ী উল্টো সাজানো (`timeId`), তাই শুধু সর্বশেষ কয়টা পড়লেই চলে।
* পাসওয়ার্ড রিসেট (Cloud Functions ছাড়া): ব্যক্তির জন্য নতুন লগইন তৈরি হয়, `map/{নতুন uid}` প্রোফাইলে নির্দেশ করে, পুরনোটা বন্ধ হয়।
